Lock Test

Checks whether music keeps playing when the iPhone screen locks. Running as: ...

How to test
  1. Tap Start YouTube test. Make sure you hear sound.
  2. Press the side button to lock the phone. Wait 30 seconds. Listen: does it keep playing?
  3. Wake the phone. If a Now Playing card shows, try its play button.
  4. Unlock, come back here, tap Share log and send it to Mal.
  5. Repeat in the other mode: this page in Safari, then added to the Home Screen (Share, Add to Home Screen) and opened from there.
Options for this run

Change these before you tap Start.

Control

A plain audio tone from this page (no YouTube). This should keep playing on lock. If it doesn't, the phone settings are the cause, not YouTube.
